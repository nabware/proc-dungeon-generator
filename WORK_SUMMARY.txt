Chip's Challenge Work Summary

Date: 2026-04-17

Overview
This workspace is centered on building and analyzing Chip's Challenge solvers and generators. The work has focused on three connected pieces: a generalized BFS-based solver, ASP-based dungeon generation and validation, and rendering tools that produce maps, path sheets, and animated route GIFs.

What was built or refined
- A generalized solver in `graph_solver_scratch.py` that can handle multiple Chip's Challenge mechanics, including chips, colored keys and locks, and all major boot/traversal rules.
- A level solving and rendering pipeline that can produce route GIFs and path-icon images for solved levels.
- An ASP generation and validation script in `asp_generate_and_validate.py` that runs clingo, converts the resulting facts into an abstract graph, and validates the generated dungeon with the solver.
- Supporting renderers and demos for level images, path icons, and abstract dungeon graphs.

Notable outputs in the workspace
- Solver and analysis artifacts for Level 1 and Level 3, including route GIFs and path-icon renders.
- Key Pyramid-related outputs such as `key_pyramid_route_scratch.gif`, `key_pyramid_two_graph_route.gif`, and associated macro-plan / room-graph images.
- Several generated random dungeon variants with JSON, map text, path-icon images, and route GIFs.
- ASP-generated examples such as dungeon, safecheck, paper-like, key-behind-lock, and unsolvable demo graphs/facts.

Key results
- The solver was able to handle both high-complexity and low-complexity levels with the same code path.
- ASP generation was made safer by adding timeout and memory limits, plus cleaner failure reporting.
- The workspace now contains a broad set of generated examples that can be used for debugging, comparison, and further solver experiments.

Current codebase shape
- `graph_solver_scratch.py` is the main solving entry point.
- `render_level_gif.py` and related renderers support visual output.
- `asp_generate_and_validate.py` bridges ASP generation and solver validation.
- `generate_key_pyramid_like_dungeon.py` and the `generated_*` files capture randomized and structured dungeon experiments.
